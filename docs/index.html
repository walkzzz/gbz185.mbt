moon add walkzzz/gbz185.mbt@0.2.0
moon update

node scripts/serve_pages.mjs
注册 → 发现 → 交互
let node = @discovery.AgentNode::from_frontmatter(
  "urn:agent:walkzzz:node-1", "演示智能体", @identity.NoIdentity, true,
  ["skill:demo"], ["text"], ["text"],
)
let proto = @aip.AipProtocol::new(node)

// GB/Z 185.3：接受注册响应（AIC 由注册中心分配）
AipProtocol::handle_register_response(proto, { accepted: true, aic: Some(aic), reason: None })

// GB/Z 185.5：吸收发现结果
let added = AipProtocol::handle_discover_response(proto, { nodes: peers })

// GB/Z 185.6：分发与接收
let env = AipProtocol::dispatch(proto, @aip.TaskRequest, "urn:agent:peer", payload)
AipProtocol::receive(peer_proto, env)

覆盖率口径：native 插桩点 811/883 = 91.8%，排除 transport_async（Windows 路径 bug）、playground、examples；moon coverage report -f full_summary 实测（2026-11-24）。

性能实测：dispatch 122.98 ns、registry_lookup 81.13 ns、envelope 往返 1.56 µs、能力检索（1000 节点 × 8 需求）101.59 µs（native release，2026-11-24）。

防重放：next_seq 与 inbox_advance 由 Z3 证明，并在 dispatch / receive 真实调用；群组扇出各对端序号空间独立。

演示口径：页面所有结果来自 playground 导出（11 个函数），与库同一份源码；发布后另有真实浏览器验收。

Under the hood

这是怎么在浏览器里跑的？

  1. 1

    playground/ 是根模块的 foreign_library 包，用 #export_name 导出 11 个非 raise 包装函数（错误折叠为 {"ok":false} / false / -1）。

  2. 2

    moon build --target js --release playground 生成一份 JS；同一份源码也可构建为 wasm-gc / native。

  3. 3

    页面直接 import 并调用：编码、校验、扇出、完整流程、能力/发现匹配、AIC、路由、工具描述全部在本地完成。

  4. 4

    语义由 verify/ 的 20 条证明义务、124 项测试与 19 点变异矩阵守护；check_pages.mjs 验证导出与语义，Pages 部署 docs/。
