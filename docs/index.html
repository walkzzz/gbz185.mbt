这是怎么在浏览器里跑的？

  1. playground/ 是 pkgtype(kind: "foreign_library") 的 MoonBit 包，用 #export_name 导出 4 个非 raise 包装函数。
  2. moon build --target js --release playground 生成 playground.js（同一份源码也可构建为 wasm-gc / native）。
  3. 页面直接 import 并调用：信封规范化、版本/协议/字段校验、群组扇出计数全部本地完成。
  4. 语义由 verify/ 的 20 条证明义务与 77 项测试守护（见测试报告）。
