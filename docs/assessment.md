## 2. 风险与缓解

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| 单人维护（巴士因子 1） | 长期演进不确定 | CONTRIBUTING + 门禁脚本 + 冻结契约；外部可 fork |
| MQ 分发 / 国密未实现（GAP-3） | 互联生产部署需自建 | 已在 CHANGELOG 声明 0.2.0 后路线；核心 sans-I/O 不阻塞上层 |
| Windows `moon prove` 平台 bug（GAP-1） | 本地证明不可跑 | WSL 通道 + CI ubuntu 复验 |
| `transport_async` mbti 未导出 async API | 下游阅读契约受限 | 以源码 doc 为准；已在 known-gaps 记录 |
| 覆盖率口径与旧文档不一致 | 评审误读 | 已统一为插桩点口径并写入 performance/TEST_REPORT |

## 3. 立项建议

1. **定位**：作为团队「智能体互联协议资产」纳入内部依赖清单，按 SemVer 维护（当前 0.x，契约冻结靠 mbti）。
2. **采纳方式**：优先在需要多智能体交互的项目中使用 `aip` + `registry` + `discovery`；传输层按需引入 `transport_async`。
3. **验收门槛**：`local_ci.sh --quick` 全绿 + 变异矩阵全 KILLED + `check_pages.mjs` 159 项通过。
4. **后续版本**：0.3.0 评估 MQ 分发与国密套件；首个 1.0 前完成跨版本兼容实证（两版并存升级路径）。
